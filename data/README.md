# Data handling

The final executed analysis uses a supplied local source file named `ccnr_microclimate_data.Rdata`. It contains the `microclimate` table used by the notebook and should be treated as read-only input.

The source record is not added by this update. Do not redistribute it, publish derivative records, or replace it with a different source without confirming the custodian's permission and documenting provenance.

The repository retains small metadata under `data/metadata/`. Large processed CSV files are reproducible notebook outputs and are excluded from new commits to keep the public repository lightweight. The final analysis reports 1,002,949 raw records, 1,002,899 hard-cleaned primary records and a 920,216-row review-screened sensitivity tier.
